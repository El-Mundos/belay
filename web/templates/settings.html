Private registries

Credentials for pulling private images (and to lift Docker Hub's anonymous rate limit). Used for both the version check and the pull. Host examples: docker.io, ghcr.io, registry.example.com:5000. Use an access token / PAT as the password where possible. Leave a row blank to remove it.

Advanced

Forward-auth proves who you are, not whether you belong here — without this, every account your identity provider authenticates can use Belay. Set a group name and only its members get in, read from the groups header your proxy sends (X-authentik-groups by default; override with --forward-groups-header). Fails closed: if no groups header arrives, access is denied — so configure the proxy to send one before setting this. The password login is exempt, so you keep a way back in.

Health probes & groups

An extra "is it really up?" check for services with no Docker HEALTHCHECK (e.g. wg-easy). If set, an update only counts as healthy once this endpoint responds — otherwise it auto-rolls-back. The target must be reachable from the Belay container.

Group ties services that must run the same version together (Authentik's server + worker are the classic pair). Give each member the same group name. If one fails, the rest are skipped and any that already updated are reverted, so the group is never left split across two versions. Services in one compose file already stop each other on failure; a group adds the revert, and can span files. A group needs at least two members.
